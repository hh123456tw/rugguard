# 趨勢策略回測（BTC、ETH 現貨，只做多或空手）

規則：價格站上 N 日均線就持有，或過去 N 日報酬為正就持有，否則持有現金。
資料：Binance 現貨日 K 線，2017-08-17 到 2026-10。訓練期 2023-01-01 之前，樣本外 2023-01-01 之後。
成本：每次進出 0.15%（手續費 0.1% + 滑價 0.05%），現金不計利息。
訊號用前一天收盤算出，在同一個收盤價成交；壓力測試另測晚一天成交、成本三倍。
重現：`python -m rugguard.trend fetch`，再 `python -m rugguard.trend report`。

## 結論

1. **一致的好處是回撤變小。** 所有趨勢規則的最大回撤都比買進持有低：BTC 訓練期 83% 降到約 64%，樣本外 53% 降到 27%–37%。主要是避開了 2018 與 2022 的長期下跌。
2. **報酬沒有可靠的改善。** 兩個幣的 Sharpe 差距，95% 信賴區間都包含 0，不能說比買進持有好。
3. **結果高度依賴行情。** BTC 在樣本外只有 1/7 的規則 Sharpe 高於買進持有，ETH 是 5/7。2023 年之後的上漲行情中，趨勢策略因為空手而落後；下跌行情中則幫忙避險。
4. **ETH 對執行很敏感。** 晚一天成交，ETH 的最佳規則樣本外報酬從 10.7% 掉到 3.8%；成本變三倍就轉負。BTC 受影響較小，仍有 42%–46%。
5. **參數選擇不穩。** 訓練期選出的規則在樣本外並不是最好的，訓練期的亮眼數字（BTC 65%、ETH 75% 年化）沒有延續。

## 限制

- 只測兩個存活至今的大幣；樣本外 3.8 年，且 BTC、ETH 多數時間在上漲。
- 7 種規則同時試，找到好結果的機率本來就會變高，這裡沒有做多重檢定校正。
- 只做多或空手；沒有做空（需考慮資金費率、爆倉）。
- 現金不計利息；有 4% 的穩定幣收益的話，趨勢策略空手時的表現會稍好。
- 成交價假設是訊號當天的收盤價，實際會有滑價；已用「晚一天」和「成本三倍」壓力測試。
- 這是研究結果，不是投資建議。
